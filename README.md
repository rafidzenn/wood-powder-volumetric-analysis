# wood-powder-volumetric-analysis
A hybrid deep learning pipeline (PointNeXt/BAAF-Net) for high-precision volumetric estimation of 3D point cloud industry data. This is a mproject I am ding for Chowa Giken Corporation, an AI starup based in Japan. This corporation, backed by the METI fund, is providing an AI Traineeship program titled " Nippon AI Dojo"

The primary work in this program will be A. working on real-world point cloud 3D data and B. onthejobtraining (one OJT every week) to address any technical or architectural complexity that we have faced in the entire week.
